# Informes de Investigación

Este directorio contiene los informes de investigación técnica y análisis de
causa raíz realizados durante el desarrollo del proyecto.

## Propósito

Cada informe documenta el proceso de investigación desde la detección de un
problema hasta la identificación de su causa raíz, incluyendo:

- Análisis de logs y trazas
- Consultas a base de datos
- Revisión de código fuente
- Diagramas de flujo y arquitectura
- Comandos de verificación utilizados
